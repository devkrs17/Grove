Staff Dashboard (Payload admin)

Non-functional wireframes, placeholder data only. Screens: orders list + detail, inventory, payouts, and partners. Access is role-based (Owner / Manager / Worker) and tenant-scoped. Manual status transitions and refunds are gated by the order state machine; each action writes an audit log.

Note: these screens represent Payload admin custom views (custom admin UI components extending apps/cms) — not a separate, hand-built Next.js dashboard app. The back-office is built by extending the Payload admin, which already provides auth, CRUD, RBAC, draft/publish, and multi-tenant scoping. (The customer storefront stays its own Next.js app, apps/web, on the Payload API.) The wireframes below are layout intent only.
