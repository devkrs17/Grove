Storefront (apps/web)

Non-functional wireframes with placeholder data only — no backend, no JS logic. Screens: product listing → product detail + add-to-cart → cart → checkout (address + review) → order confirmation. Cart persists client-side (localStorage); placing an order calls the server-authoritative create-order route.
