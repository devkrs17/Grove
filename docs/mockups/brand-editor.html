Brand & Theme Editor

A friendly, no-code editor for a tenant's theme — colors, typography, logo and identity — with a live storefront preview. Click the tabs (Identity / Colors / Typography) to switch sections. It edits the existing brand-configs collection (and pulls site identity from sites); the storefront reads those values at runtime, so publishing re-skins the live site with no CSS edits. Placeholder data only — the colored preview shows an example palette.
