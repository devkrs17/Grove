🌳 Grove Platform

Platform Documentation & UI Mockups

Grove is a multi-tenant commerce + settlement + fulfillment SaaS platform. One codebase, one deployment, one Payload instance — each customer organization is resolved at runtime by hostname. There are no forks.

Generalized infrastructure. The first tenant is a regulated-goods commerce & delivery operator; everything operator-specific lives in per-tenant config and swappable provider adapters — never in the core.

How this platform stays generic. The same engines power any tenant. Industry-specific behavior (eligibility gates, credential checks, a particular bank/ACH provider, fee splits) is expressed through configuration and provider adapters behind generic interfaces.

Generic nouns only Provider-agnostic integrations Per-tenant config drives behavior Multi-tenant from day one Determinism over model calls
