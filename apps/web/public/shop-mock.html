Proposed Payload data flow — Shop / PLP

The shop page is a query view over the existing products collection (no new model). The grid is one call: payload.find('products', { where: { _status: { equals: 'published' }, tenant: { equals: siteTenant }, …facets } }). Filter facets are derived from products.category, the brand field, and the price range; sort maps to the Payload sort param. Cards reuse featuredImage → media.
